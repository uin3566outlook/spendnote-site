SPENDNOTE

นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 9 สิงหาคม 2569

นโยบายความเป็นส่วนตัวนี้อธิบายว่า yehuanwei (“SpendNote” หรือ “เรา”) จัดการข้อมูลเมื่อคุณใช้แอป SpendNote อย่างไร

1. ขอบเขตและผู้ให้บริการ

นโยบายนี้ใช้กับแอป SpendNote บน iOS และเว็บไซต์นี้ แอปให้บริการโดย yehuanweiหากมีคำถามเรื่องความเป็นส่วนตัว โปรดติดต่อ airproductlab@gmail.com.

นโยบายนี้ไม่ครอบคลุมการจัดการข้อมูลของ Apple ผ่าน App Store, Apple ID หรือบริการชำระเงิน บริการเหล่านั้นอยู่ภายใต้นโยบายของ Apple เอง

2. การออกแบบที่เก็บในเครื่องเป็นหลัก

SpendNote ออกแบบให้ทำงานโดยไม่ต้องมีบัญชีหรือระบบหลังบ้าน SpendNote ในเวอร์ชันปัจจุบัน ข้อมูลบัญชีอยู่ในอุปกรณ์ของคุณ SpendNote ไม่ส่งข้อมูลบัญชีให้เรา และเราไม่มีบริการรับหรือจัดเก็บข้อมูลนั้น

SpendNote ไม่มี SDK โฆษณาหรือวิเคราะห์ของบุคคลที่สาม เราไม่ขายข้อมูลส่วนบุคคล ไม่ใช้เพื่อโฆษณาข้ามแอป และไม่แบ่งปันกับนายหน้าข้อมูล

เว็บไซต์นี้เป็นแบบคงที่ ไม่ใช้คุกกี้ การวิเคราะห์ หรือการติดตาม เมื่อคุณเข้าชมเว็บหรือเปิดหน้ากฎหมายหรือช่วยเหลือจากในแอป iOS จะโหลดเว็บเดียวกันจาก GitHub Pages ซึ่งอาจประมวลผลข้อมูลการเชื่อมต่อมาตรฐาน เช่น ที่อยู่ IP ข้อมูลเบราว์เซอร์หรือ User-Agent, URL ที่ขอ และเวลาที่ขอ ในบันทึกเซิร์ฟเวอร์ตาม คำชี้แจงความเป็นส่วนตัวของ GitHubคำขอเหล่านี้ไม่มีข้อมูลบัญชีของคุณ เราไม่เพิ่มตัวติดตามในหน้าเหล่านี้หรือใช้ข้อมูลการเชื่อมต่อเพื่อโฆษณาหรือสร้างโปรไฟล์

3. ข้อมูลที่เก็บในอุปกรณ์

เพื่อให้บริการบันทึกบัญชี งบประมาณ การเตือน และการปรับแต่ง แอปเก็บข้อมูลที่คุณป้อนหรือเลือกไว้ในอุปกรณ์ ซึ่งอาจรวมถึง:

  • รายละเอียดธุรกรรมและบิลประจำ เช่น จำนวนเงิน วันที่ หมวด ชื่อ ร้านค้า และบันทึก
  • รายละเอียดงบ หมวดที่กำหนดเอง ภูมิภาค และสกุลเงินที่เลือก
  • การตั้งค่าแอป รวมถึงล็อก Face ID และการเตือน
  • ไฟล์ CSV และข้อมูลสำรองที่สร้างในเครื่องขณะที่ยังพร้อมให้คุณใช้งาน และ
  • ภาพรวมสรุปแบบจำกัดใน App Group ของ SpendNote สำหรับวิดเจ็ต

เราใช้ข้อมูลนี้เฉพาะในอุปกรณ์เพื่อให้ฟีเจอร์ที่คุณร้องขอ และเราเข้าถึงข้อมูลนั้นไม่ได้

4. ฟีเจอร์ของอุปกรณ์

  • Face ID หากเปิดล็อก Face ID การยืนยันตัวตนทำโดย iOS SpendNote รับเพียงผลยืนยัน และไม่เคยรับหรือจัดเก็บแม่แบบชีวมิติของคุณ
  • การแจ้งเตือน หากอนุญาตการแจ้งเตือน SpendNote จะตั้งเวลาเตือนงบในเครื่องผ่าน iOS คุณเปลี่ยนสิทธิ์ในตั้งค่า iOS และปิดการเตือนในแอปได้
  • วิดเจ็ต วิดเจ็ตหน้าจอโฮมและหน้าจอล็อกอ่านภาพรวมสรุปในเครื่องที่มียอดรวม สถานะงบ สกุลเงิน และสถานะการแสดงผล ไม่อ่านธุรกรรมรายรายการ ร้านค้า หรือบันทึก

5. การสมัครสมาชิกและ Apple

การสมัคร SpendNote Pro จำหน่ายและดำเนินการโดย Apple ผ่าน StoreKit และบัญชี Apple ของคุณ ผู้พัฒนาตั้งค่าสินค้า ระดับราคา และข้อเสนอเริ่มต้นใน App Store Connect Apple แสดงราคาตามหน้าร้านและจัดการการเรียกเก็บเงิน ข้อมูลชำระเงิน การคืนเงิน และการสมัครสมาชิก SpendNote ตรวจสอบสิทธิ์ StoreKit ของสินค้าเพื่อปลดล็อกหรือกู้คืน Pro เราไม่รับหรือเก็บหมายเลขบัตร ที่อยู่เรียกเก็บเงิน หรือตัวระบุบัญชี Apple ของคุณ

6. การส่งออก สำรองข้อมูล และบริการบุคคลที่สาม

ไฟล์ CSV และข้อมูลสำรองจะสร้างเมื่อคุณเลือกเท่านั้น หากใช้แผ่นแชร์ iOS แอปไฟล์ หรือปลายทางอื่นเพื่อบันทึกหรือส่งไฟล์ คุณเป็นผู้ส่งไฟล์ที่เลือกไปยังปลายทางนั้น การจัดการไฟล์ของผู้รับหรือผู้ให้บริการปลายทางอยู่ภายใต้แนวปฏิบัติความเป็นส่วนตัวของตนเอง

Apple, GitHub และปลายทางที่คุณเลือกดำเนินงานภายใต้ข้อกำหนดและนโยบายความเป็นส่วนตัวของตนเอง หากเราจ้างผู้ให้บริการประมวลผลข้อมูลส่วนบุคคลแทนเรา เราจะกำหนดให้มีการคุ้มครองตามนโยบายนี้และกฎหมายที่ใช้บังคับ

7. การเก็บรักษาและลบ

SpendNote เก็บข้อมูลบัญชีไว้ในอุปกรณ์จนกว่าคุณจะลบ กู้คืนข้อมูลสำรองอื่นทับ หรือลบแอปตามการตั้งค่าอุปกรณ์ ในแอป ลบข้อมูลในเครื่อง จะลบธุรกรรม งบ บิลประจำ และหมวดที่กำหนดเอง ล้างภาพรวมวิดเจ็ต และยกเลิกการเตือนงบที่รออยู่ หมวดเริ่มต้นอาจยังคงอยู่เพื่อให้แอปทำงานต่อได้

คุณเป็นผู้ควบคุมสำเนาที่ส่งออกหรือสำรอง โปรดลบสำเนาเหล่านั้นจากตำแหน่งหรือบริการผู้รับแยกต่างหาก เนื่องจากเราไม่ได้รับข้อมูลบัญชี เราจึงไม่สามารถเรียกคืนหรือลบข้อมูลจากอุปกรณ์หรือปลายทางที่คุณเลือกได้

8. ทางเลือกและสิทธิ์ความเป็นส่วนตัว

คุณจัดการข้อมูลในแอปได้โดยตรง ได้แก่ แก้ไขหรือลบรายการ ส่งออก CSV สร้างหรือกู้คืนข้อมูลสำรอง เปิดหรือปิดการเตือน และปิดล็อก Face ID หากกฎหมายความเป็นส่วนตัวให้สิทธิ์เพิ่มเติม คุณติดต่อเราได้ตามข้อมูลข้างต้น ความสามารถในการดำเนินการของเรามีจำกัด เพราะเราไม่เก็บข้อมูลบัญชีไว้ในระบบของเรา

9. เด็ก

SpendNote ไม่ได้มุ่งให้เด็กใช้งาน โปรดอย่าใช้แอปหากอายุต่ำกว่าเกณฑ์ขั้นต่ำในการยินยอมประมวลผลข้อมูลตามกฎหมาย หากเชื่อว่ามีเด็กให้ข้อมูลส่วนบุคคลแก่เราโดยตรง โปรดติดต่อเรา และเราจะจัดการคำขอตามกฎหมายที่ใช้บังคับ

10. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เมื่อแนวปฏิบัติข้อมูลของแอปหรือข้อกำหนดที่ใช้บังคับเปลี่ยน หากรุ่นอนาคตเพิ่มการซิงก์ iCloud บัญชี การวิเคราะห์ โฆษณา ระบบหลังบ้าน หรือ SDK บุคคลที่สามที่จัดการข้อมูลส่วนบุคคล เราจะปรับปรุงนโยบายและการเปิดเผยความเป็นส่วนตัวใน App Store ก่อนเปิดใช้ วันที่อัปเดตล่าสุดแสดงวันที่แก้ไขนโยบายครั้งล่าสุด

11. ติดต่อ
