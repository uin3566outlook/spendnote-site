プライバシーポリシー

最終更新： 2026年8月9日

本プライバシーポリシーは、 yehuanwei （「SpendNote」または「当社」）が SpendNote アプリの利用時にどのように情報を取り扱うかを説明します。

1. 適用範囲と提供者

本ポリシーは SpendNote iOS アプリと本ウェブサイトに適用されます。アプリは yehuanweiが提供します。プライバシーに関するお問い合わせ先： airproductlab@gmail.com.

本ポリシーは、App Store、Apple ID、決済サービスを通じた Apple の情報の取り扱いには適用されません。これらには Apple 独自のポリシーが適用されます。

2. ローカル優先の設計

SpendNote はアカウントも自社バックエンドも不要な設計です。現行版では帳簿データはデバイス内に残ります。SpendNote は帳簿データを当社に送信せず、当社もそれを受信・保存するサービスを運営しません。

SpendNote に広告 SDK や第三者の分析 SDK は含まれません。個人情報を販売したり、アプリをまたぐ広告に使ったり、データブローカーと共有したりしません。

本サイトは静的ページで、Cookie、分析、追跡を使いません。サイトへのアクセス時やアプリ内で法律・サポートページを開く際、iOS は GitHub Pages から同じサイトを読み込みます。GitHub Pages は、IP アドレス、ブラウザや User-Agent、リクエスト URL、時刻などの標準接続情報を、サーバーログで同社の GitHub プライバシーステートメントに基づき処理する場合があります。これらのリクエストに帳簿データは含まれません。当社はこれらのページに追跡機能を追加せず、接続情報を広告やプロファイリングに使いません。

3. デバイスに保存する情報

記帳、予算、リマインダー、個人設定を提供するため、入力・選択した情報をデバイス内に保存します。次の情報が含まれる場合があります。

  • 金額、日付、カテゴリ、タイトル、加盟店、メモなどの取引・定期支払い情報。
  • 予算の詳細、独自カテゴリ、地域・通貨の選択。
  • Face ID ロック、リマインダーなどのアプリ設定。
  • 利用可能な間の、ローカル生成の CSV とバックアップファイル。
  • SpendNote ウィジェット向けに App Group 内に保存する限定的な集計スナップショット。

これらの情報は、求められた機能を提供するためにデバイス内だけで使います。当社はアクセスできません。

4. デバイスの機能

  • Face ID。 Face ID ロックを有効にした場合、認証は iOS が行います。SpendNote が受け取るのは認証結果のみで、生体認証テンプレートを受信・保存することはありません。
  • 通知。 通知を許可すると、SpendNote は iOS を通じてローカルの予算アラートを設定します。iOS の「設定」で通知権限を変更し、アプリ内でアラートをオフにできます。
  • ウィジェット。 ホーム画面とロック画面のウィジェットは、合計、予算状況、通貨、表示状態を含むローカル集計スナップショットを読み取ります。個別の取引記録、加盟店、メモは読み取りません。

5. サブスクリプションと Apple

SpendNote Pro のサブスクリプションは、StoreKit と Apple アカウントを通じて Apple が販売・処理します。開発者は App Store Connect で商品、価格帯、初回限定オファーを設定します。Apple は該当ストアの価格を表示し、請求、支払い情報、返金、サブスクリプション管理を担当します。SpendNote は商品の StoreKit 利用権を確認し、Pro を解放・復元します。当社はカード番号、請求先住所、Apple アカウント識別子を受信・保存しません。

6. 書き出し、バックアップ、第三者サービス

CSV とバックアップファイルは、ユーザーが作成を選んだときだけ生成されます。iOS の共有シート、「ファイル」などで保存または送信する場合、選んだファイルをその送信先に渡すのはユーザーの操作です。受信者や保存先提供者のファイルの取り扱いには、それぞれのプライバシー慣行が適用されます。

Apple、GitHub、およびユーザーが選ぶ送信先は、それぞれの規約とプライバシーポリシーに従って運営されます。当社がサービス提供者に個人情報の処理を委託する場合、本ポリシーおよび適用法に沿う保護を求めます。

7. 保存期間と削除

SpendNote は、削除、別のローカルバックアップによる上書き、またはデバイスの設定に従うアプリの削除まで、帳簿データをデバイス内に保持します。アプリ内の ローカルデータを削除 を選ぶと、取引、予算、定期支払い、独自カテゴリが削除され、ウィジェットの帳簿スナップショットと予約中の予算通知も消去されます。アプリの動作に必要な既定カテゴリは残る場合があります。

書き出しやバックアップのコピーはユーザーが管理します。保存先や受信先のサービスから個別に削除してください。当社は帳簿データを受け取らないため、デバイスや指定された保存先から取得・削除できません。

8. プライバシーの選択と権利

アプリ内で、記録の編集・削除、CSV 書き出し、ローカルバックアップの作成・復元、リマインダーの切り替え、Face ID ロックの無効化ができます。適用されるプライバシー法により追加の権利がある場合は、上記連絡先からご連絡ください。当社のシステムに帳簿データを収集・保持しないため、対応できる範囲には限りがあります。

9. お子様について

SpendNote はお子様向けではありません。適用法の定めるデータ処理への同意年齢に満たない場合は利用しないでください。お子様が当社に直接個人情報を提供したと思われる場合はご連絡ください。適用法に従って対応します。

10. ポリシーの変更

データの取り扱いや適用要件の変更に応じ、本ポリシーを更新する場合があります。今後 iCloud 同期、アカウント、分析、広告、バックエンド、個人情報を扱う第三者 SDK を追加する場合、有効にする前に本ポリシーと App Store のプライバシー開示を更新します。「最終更新」は本ポリシーの最終改訂日を示します。
